# Bowya | Brother Birthday Celebration Studio 🎉

A luxury animated, personalized birthday celebration website designed for a beloved brother.

## ✨ Features
- **Cinematic 3-Second Landing Countdown**: Dramatic countdown with progress ring, sound effects, fireworks burst, and celebratory chime.
- **Heartfelt Wishes Pavilion**: 5 detailed long-form letters with real-time typewriter text animation and 1-click clipboard copying.
- **Sibling Chronicles Timeline**: 7 animated chapters of growing up together with a glowing pulse laser beam and interactive emoji badges.
- **Interactive Birthday Cake**: Candle blowout with animated smoke puff physics, sound effects, and confetti.
- **Mystery 3D Gift Box**: Interactive gift box that opens to reveal an official Birthday VIP voucher.
- **Polaroid Photo Wall**: Nostalgic 3D tilted photo cards with a full-screen lightbox preview and captions.
- **Brotherhood Trivia Quiz**: Interactive trivia test with instant feedback and score celebration.
- **Keepsake Certificate**: Printable/downloadable "World's Best Brother Certificate of Honor".
- **Floating Interactive Balloons**: Poppable background balloons with synthesized sound effects.
- **4 Theme Palettes**: Luxury Gold, Cyber Blue, Sunset Rose Gold, and Emerald Royale.
- **Instant Customizer**: Edit brother and sister names live across the entire website.

## 🚀 Getting Started
Simply open `index.html` in any modern web browser or deploy directly to GitHub Pages.
